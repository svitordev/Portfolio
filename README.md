# 🌐 Portfólio | Svitor.dev

Bem-vindo ao meu portfólio pessoal desenvolvido com **React**, **TypeScript** e **Vite**! Este projeto tem como objetivo apresentar minhas habilidades, tecnologias que domino, projetos realizados e formas de contato.

🔗 **Acesse agora:** [svitordev.vercel.app](https://svitordev.vercel.app)

---

## ✨ Funcionalidades

- 🌓 **Alternância entre Tema Claro/Escuro**
- 🌐 **Suporte a Múltiplos Idiomas** com `i18next`
- 🧑‍💻 **Exibição de Tecnologias Conhecidas**
- 📁 **Seção de Projetos com Destaques**
- 📄 **Currículo para Download**
- 📬 **Formas de Contato Direto**
- ⚡ **Animações Suaves** com GSAP
- ✅ **Acessível e Responsivo**

---

## 🚀 Tecnologias Utilizadas

### Frontend
- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [React Router DOM](https://reactrouter.com/)
- [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
- [React Icons](https://react-icons.github.io/react-icons/)

### Internacionalização
- [`i18next`](https://www.i18next.com/)
- `react-i18next`
- `i18next-http-backend`
- `i18next-browser-languagedetector`
